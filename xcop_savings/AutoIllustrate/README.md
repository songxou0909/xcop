# Install Amyloid Illustrator files here

The feature labelled `AutoIllustrate` in `xcop` uses the third-party **Amyloid Illustrator** software by Michael R. Sawaya and David Eisenberg. These files are not claimed as Songxian Ou's work and are not redistributed by this repository.

Obtain the source files from the creators' official record:

<https://doi.org/10.5281/zenodo.15218932>

Follow the instructions on that page to compile the Fortran programs, then place the compiled programs and `autoillustrate.com` directly in this directory. The expected runtime filenames are:

```text
accessiblesurfacearea_v07.2u
autoillustrate.com
autoschematic171
isolatefibrilasu_v04
pdbclean_v02
rotxz
```

Review and comply with all terms supplied by the creators. Do not commit or redistribute these third-party files through this repository unless you have explicit permission to do so.
